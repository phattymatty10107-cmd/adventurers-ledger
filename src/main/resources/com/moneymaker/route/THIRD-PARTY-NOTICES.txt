Third-party data in Adventurer's Ledger's route finder
======================================================

The route finder's own code (the com.*.route classes) was written for this plugin.
The data it reads is not:

1. Shortest Path  -  https://github.com/Skretzo/shortest-path  (BSD 2-Clause)
   collision-map.zip, item-variations.tsv, everything in transports/, and the bank and boss
   tiles in places.txt / plusplaces.txt are copied from, or taken from, that project's resources.
   Its licence file is reproduced in full below, as published.

2. RuneLite  -  https://github.com/runelite/runelite  (BSD 2-Clause)
   The quest start points, farming patch tiles and dungeon entrances come from RuneLite's world
   map plugin (QuestStartLocation, FarmingPatchLocation, DungeonLocation):
